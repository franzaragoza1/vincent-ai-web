How it works

FAQ

Which sims does it support?

iRacing only, for now.

What do I need?

A Windows PC, iRacing, a microphone, an internet connection and a Discord account to sign in. VINCENT uses cloud AI and voice, so you bring one OpenRouter API key — the setup wizard walks you through it and checks it for you.

How much does a race cost to run?

It depends on the AI model you choose in settings — cheaper models cost cents per race, the best ones a bit more. The app shows token usage live so you always know.

Can I use it in official races?

Yes — that's what it's built for. VINCENT works like the spotter and overlay apps drivers already use in official races: it only reads the telemetry iRacing exposes to every app, and talks to you. It never touches the car or the sim.

Is it really free?

Yes. VINCENT itself costs nothing and has no paid version. The only cost is the AI and voice usage, which you pay straight to OpenRouter — we don't get a cent of it.

Why do I need to sign in?

To download it and to use it, with your Discord account. It lets us know who's using VINCENT, stop anyone reselling it, and switch off a broken version fast. Each account can use it on up to 3 PCs; you can see and remove them in your account. If your internet drops mid-race, it keeps working.

Where do my API keys go?

They are stored in the Windows Credential Manager on your PC and are only sent to the service each one belongs to. They are never sent to us. Tip: create a key just for VINCENT and give it a credit limit in OpenRouter, so a lost key can never cost you more than that.

Windows says “unknown publisher”

The first time, SmartScreen may warn you. Click More info → Run anyway. After that VINCENT updates itself: it downloads new versions when it opens and installs them when it closes.
